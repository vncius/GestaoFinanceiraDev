# Backlog — ideias para análise e melhoria futura

> Itens registrados a pedido do usuário em 2026-10-13. **Não fazem parte do plano em andamento** (`docs/plano-simplificacao-ux.md`); analisar e planejar depois.

## B1 — Reservas tipo "caixinhas" (visão de patrimônio)
- Reservas financeiras apenas para **visualização do patrimônio total** (não entram no fluxo do dia a dia), no estilo das caixinhas do Nubank.
- Ajuste manual do saldo de cada reserva, **guardando histórico de todos os ajustes** (data, valor anterior, novo valor, motivo).

## B2 — Relatório mensal com IA sobre hábitos de consumo
- Relatório mensal gerado pela IA analisando os gastos médios dos últimos meses: o que está mudando, se o custo de vida está aumentando ou não.
- Exige **log de auditoria das alterações de planejamento** (ex.: planejado 1.000 → ajustado para 1.500; no mês seguinte ficou 1.200), para a IA identificar padrões.
- Dicas acionáveis, ex.: "todo mês você passa dos 1.000 em compras; considere planejar 1.200 para essa despesa".
- Depende de existir um conceito de valor planejado por categoria/mês (hoje não existe).
